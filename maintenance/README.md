# Maintenance Management

## 1. 目的

このディレクトリは、パッチ適用・バージョンアップ・設定変更など、日々のメンテナンス業務を管理するためのものです。

## 2. 対象

| 対象 | 内容 |
|---|---|
| OS | セキュリティパッチ、カーネル更新 |
| Apache | モジュール更新、設定変更 |
| JDK | バージョンアップ |
| WebLogic | PSU/CPU適用想定 |
| Oracle | パッチ適用想定 |

## 3. メンテナンス基本方針

すべてのメンテナンス作業は以下の流れで実施します。

1. 事前確認
2. 影響調査
3. バックアップ
4. 作業実施
5. 事後確認
6. 障害時ロールバック
7. 証跡保存

## 4. 必須成果物

各メンテナンス作業では、以下を作成します。

```text
procedure.md
rollback.md
evidence-template.md
```

## 5. ロールバック方針

作業前に必ず切り戻し条件を明確にします。

例：

- サービス起動不可
- 接続確認失敗
- エラーログ増加
- 性能劣化
- 利用者影響あり

## 6. 証跡方針

メンテナンス作業では、以下を証跡として取得します。

- 作業前バージョン
- 作業前サービス状態
- バックアップ取得結果
- 作業ログ
- 作業後バージョン
- 接続確認結果
- ロールバック有無
