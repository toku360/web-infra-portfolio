# 00. ポートフォリオ概要

## 1. 目的

本ポートフォリオは、銀行系Webシステムを想定したインフラ運用・設計能力を示すためのものです。

単にミドルウェアを構築するだけではなく、実務で必要となる以下の観点を重視します。

- 設計
- 構築
- 運用
- 監視
- 障害対応
- 変更管理
- パッチ適用
- ロールバック
- 証跡管理

## 2. 想定する業務領域

本ポートフォリオでは、以下のような銀行系システム運用業務を想定しています。

| 領域 | 内容 |
|---|---|
| Linux | RHEL/Rocky系サーバ運用 |
| Apache | Webフロント、Reverse Proxy、TLS |
| WebLogic | Javaアプリケーション基盤 |
| Oracle | RDBMS、接続管理、障害切り分け |
| AWS | 基礎的なクラウドインフラ |
| Terraform | dev/prod環境管理 |
| 運用管理 | 変更管理、障害対応、メンテナンス |

## 3. 想定アーキテクチャ

## 4. dev/prodの位置付け

### dev

dev環境は、検証・障害演習・変更作業の確認を行う環境です。

主な用途は以下です。

- 設定変更の検証
- パッチ適用前検証
- 障害再現
- ロールバック検証
- 手順書の妥当性確認

### prod

prod環境は、本番想定の設計を行う環境です。

実際の本番環境を構築するのではなく、以下を文書・Terraformコードで表現します。

- 本番想定構成
- 変更前確認
- 作業承認
- 作業証跡
- ロールバック判断
- 障害時エスカレーション

## 5. 成果物方針

各Markdownは、数行のメモではなく、実務で利用できる設計書・手順書として作成します。

最低限、以下の章を含めます。

- 目的
- 前提
- 対象範囲
- 設計方針
- 手順
- 確認方法
- 障害時対応
- ロールバック
- 証跡
- 注意事項

## 6. 評価されるポイント

このポートフォリオでは、以下の評価を狙います。

| 評価者 | 評価ポイント |
|---|---|
| フリーランスエージェント | 技術範囲、実務感、成果物の見やすさ |

| 技術面接官 | Linux/Apache/WebLogic/Oracle/AWSの理解 |
